# Mini Redis 

This project is a recreation of key store system for key and corresponding data, for quick random access for quick access. This system only designed to store key as strings and data as string with accessible GET, SET, DEl to add, edit, delete.

## Entry Points
- GET : retrieve the stored object from a known key.
- SET : set a key and object to be retrieve later.
- DEL : delete a know key from store data base.

- client : python test scripts and client access scripts.
